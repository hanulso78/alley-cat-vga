골목 고양이 (ALLEY CAT) - 1984년 원판 + VGA

  1984년 IBM 이 내고 Bill Williams (SynSoft) 가 어셈블리로 짠 ALLYCAT.EXE 를
  역어셈블해서 C 로 옮긴 판입니다.  게임 규칙, 속도, PC 스피커 소리는
  원판 그대로이고, 화면만 다릅니다.

    - 원판은 CGA 320x200 4색으로 그렸습니다.  이 판은 같은 화면을
      VGA 320x200 (모드 13h) 에 똑같이 보여 줍니다.
    - 원판은 CPU 속도에 따라 빨라지는 곳이 있어서, IBM PC (8088 4.77MHz)
      빠르기에 맞춰 기다립니다.

게임
  도둑고양이가 되어 골목의 쓰레기통, 담장, 빨랫줄을 타고 올라가 열린
  창문으로 뛰어듭니다.  방마다 할 일이 있습니다.
      어항        어항에 뛰어들어 물고기를 모두 잡는다 (뱀장어와 숨 조심)
      책장        책장 위의 화분 셋을 떨어뜨린다 (거미 조심)
      치즈        쥐구멍에서 나오는 쥐 넷을 잡는다
      새장        새장을 떨어뜨리고 새를 잡는다
      잠자는 개들 밥그릇의 우유를 다 마신다 (개가 깨지 않게)
  방 안에서는 빗자루가 쫓아옵니다.  골목에서는 불독과 창문에서 던지는
  물건을 피합니다.  방을 깨면 사랑의 방으로 가는 창문이 열리고, 꼭대기의
  암고양이에게 가면 판을 깹니다.

조작
  처음    조이스틱을 쓸지 (Y/N),  난이도 K 아기 / H 집 / T 수 / A 골목 고양이
  게임    화살표          움직이기
          PgUp PgDn       대각선 (오른쪽 위, 오른쪽 아래)
          Home End        대각선 (왼쪽 위, 왼쪽 아래)
          Alt             뛰기 / 사랑의 방에서 선물 들기와 놓기
          Esc             잠깐 멈춤
          Ctrl-S          소리 켜고 끄기
          Ctrl-M          메뉴           Ctrl-R  다시 시작
          Ctrl-Y          도스로

실행
  DOSBox 나 도스에서 이 폴더로 가서  ALLEY  라고 칩니다.
  배경음악과 효과음은 PC 스피커로 나옵니다.

이 폴더의 파일
  ALLEY.EXE      게임
  CWSDPMI.EXE    도스에서 32비트로 돌리기 위한 DPMI 서버 (같이 있어야 합니다)
